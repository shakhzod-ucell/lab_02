# Short word guide

Technical words keep their exact meaning. Use this guide when a word is new.

| Word | Simple meaning |
|---|---|
| API | The function names, inputs, and outputs your code must use |
| DataFrame | A pandas table |
| Grain | What one row means |
| Key | Field or fields used to identify a record |
| Schema | Required columns and their data rules |
| Validate | Check that input follows its rules |
| Normalize | Put valid input in one agreed form, such as uppercase USD |
| Mutation | Changing an existing object in place |
| UTC | A common time standard used to compare times from different zones |
| Timezone/offset | Information showing how a local time relates to UTC |
| NaN | A numeric missing-value marker: not a number |
| Infinity | A nonfinite value such as positive or negative infinity |
| None | Python's value for no result; becomes null in JSON |
| Boolean | True or False |
| ddof=1 | Divide by n−1 when calculating sample variance |
| Population | The full group about which you want to learn |
| Sample | The observations available for analysis |
| Independent | One observation does not depend on another, under the model assumptions |
| Stable sort | Equal sorting keys keep their earlier relative order |
| Reproducible | The stated inputs and steps give the same result again |
| Evidence | A checked result, table, figure, or code behavior supporting a claim |
| Limitation | A reason the result cannot answer every question |
| Commit SHA | Git identifier for one saved version of files |
| Pull request | A GitHub page used to review proposed changes |

Use the exact function and column names in FUNCTION_GUIDE.md, even if their names are technical.
